Hex terrain tiles, 64×64, flat-top, seen from above (PixelLab
`create_tiles_pro`, hex, top-down, segmentation outlines). The hexagon fills
the top 55 rows; trees and roofs may spill below it. `<terrain>-<n>.png`:
every variant of a terrain is picked per hex, so the board does not repeat.
Region and god stage tint them in `board.rs`.
