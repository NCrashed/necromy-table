Necromy Table — сборка под Windows
==================================

Распакуй архив целиком, одной папкой, и запускай necromy-table.exe оттуда.
Рядом с exe должны лежать папка assets и два файла dxcompiler.dll и
dxil.dll: без них компиляция шейдеров на старте снова займёт минуты.

Первый запуск может подумать несколько секунд: шейдеры компилирует драйвер
на твоей машине, заранее положить результат в сборку нельзя. Если старт или
первая партия висят минутами — это та самая поломка, пришли лог.

Как снять лог
-------------
Запусти run-with-log.bat вместо exe: то же самое, только всё пишется в
log.txt рядом. Этот файл и пришли. Важные строки:
  dx12 shader compiler: DynamicDxc { ... }   — нашёлся быстрый компилятор
  AdapterInfo { ... backend: Vulkan ... }    — какая видеокарта и путь

Если тормозит или картинка сломана
----------------------------------
Можно попробовать другой графический путь без пересборки. Открой
«Командную строку» в папке с игрой и набери:

  set WGPU_BACKEND=dx12
  necromy-table.exe

Вместо dx12 бывает vulkan. Напиши, какой оказался быстрее.

Сетевая игра идёт на общий сервер по умолчанию. Прогресс обучения лежит в
%LOCALAPPDATA%\necromy-table.
